# Plan: Beginner UX — slower exercises, wider pitch window, in-graph level + coaching HUD

## Context (user feedback)

1. **Exercise bars move too fast / not enough gaps** — complete beginner.
2. **Pitch “loops around”** when too low/high — extend the vertical window **down and up** (no octave wrap).
3. **Only pitch dots + tiny corner volume bar** — volume belongs in the **main visual graph**; user wants to **see what’s improved**.

### Current code (verified)

| Issue | Location | Fact |
|-------|----------|------|
| Exercise speed | `client/src/components/main/exercises.tsx` | scale: `i*500` / 450 ms → **50 ms gap**; siren: continuous 250 ms; interval: 100 ms gap; range: 20 ms gap; hold: 500 ms gap (only OK one) |
| Pitch wrap | `display/src/pitch-display/index.ts` L321, L392 | `scaleY((pitch + NOTE_OFFSET) % 24)` with domain **[0,23]** → wraps every 2 octaves |
| Staff labels | `display/src/constants/index.ts` | 12 names from F; no octave numbers; `NOTE_OFFSET = 7` |
| Level UI | `client/src/components/pitch/index.tsx` L243–261, L471 | fixed **top-right** 120×10 px; not on pitch canvas |
| Live coaching | practice screen | canvas + transport only; **ScoreSummary only after Stop**; Help has no feature list |

`pitch` / `melodyPitch` are already MIDI floats; `rms` already flows through `PitchMonitor` → `PitchComponent` → pitch track — only **display** lacks it.

---

## Goals

1. Beginner-default exercise timing: long notes + clear rests.
2. Vertical staff spans a wide MIDI range with **no `% 24` wrap**; octave-aware labels.
3. Input level is a strip **inside** the pitch canvas (time-aligned with dots); corner meter removed.
4. Always-on practice HUD (note, cents, level) + first-run tip + Help “what’s in the coach”.

## Non-goals

- Tempo UI / difficulty toggle (bake beginner defaults into code).
- Backend/sidecar changes; scoring formula changes.

---

## Implementation (ordered)

### Step 1 — Pitch range without octave wrap (fix the bug first)

**Files:** `display/src/constants/index.ts`, `display/src/pitch-display/index.ts`

- Add `PITCH_MIN = 36` (C2), `PITCH_MAX = 84` (C6) → domain **[36, 84]**.
- `resize()`:  
  `scaleY.domain([PITCH_MIN, PITCH_MAX]).range([h - margin, margin])`  
  with `margin ≈ h / 40` (staff still leaves room for level ribbon below).
- **Delete both** `(pitch + NOTE_OFFSET) % 24` uses (`drawNotes` ~L321, `drawMelody` ~L392).  
  Call `scaleY(pitch)` / `scaleY(melodyPitch)` directly (clamp only for off-range: `Math.min(PITCH_MAX, Math.max(PITCH_MIN, pitch))` so extreme notes sit at edge, never wrap).
- Keep `melodyPitch` octave-fold in `pushFrequency` for **scoring/color** — only Y mapping changes.
- `drawBackground()`: for `m = 36..84` draw line at `scaleY(m)`.  
  Label **natural notes only** (pitch class in `{0,2,4,5,7,9,11}`):  
  `` `${NOTE_STRINGS[(m + NOTE_OFFSET) % 12]}${Math.floor(m / 12) - 1}` `` → `C2`…`C6`.  
  Sharps: faint lines, no text (avoid clutter). If spacing ≥16 px, may label all.
- Keep `NOTE_STRINGS` / `NOTE_OFFSET` for **label text only**, not scale math.

**Exit:** low C2 at bottom, high C6 at top; dots never teleport across octaves; melody bars align with labels.

---

### Step 2 — Level ribbon on the main graph

**Files:** `display/src/pitch-display/index.ts`, `client/src/components/pitch/index.tsx`, `client/src/index.css`

**Preferred approach (time-aligned with pitch history):**

- Extend `IFrequency` with optional `rms?: number`.
- Client `updatePitch`: include `rms: rms ?? 0` in `pushFrequency({ frequency, clarity, time, rms })`.
- In `drawNotes()` after pitch dots, draw **RMS ribbon** at canvas bottom (~12% height):
  - For each frequency sample: rect at `x = scaleX(t - now)`, width ≈ sample spacing (clamp 4–10 px),  
    `height = clamp(rms * 4, 0, 1) * ribbonH`, anchored to bottom.
  - Color: grey `rms < 0.01`, green `0.01–0.35`, amber/red `> 0.35`.
- Staff `scaleY` range already reserved above ribbon (Step 1 margin).
- **Remove** `LevelMeter` component and its mount; delete `.level-meter*` CSS.

**Exit:** louder singing fills a scrolling strip under the staff on the **same** graph; corner bar gone.

### Step 3 — Practice HUD + “what’s improved”

**Files:** `client/src/components/pitch/index.tsx`, `client/src/index.css`, `client/src/components/main/about.tsx`, `client/src/translations/{en-US,es-ES,fi-FI}.json`

**A. Live HUD** (fixed top-center over canvas, `pointer-events: none`):

| Field | Source |
|-------|--------|
| Current note (`A3`) | latest `freq` → MIDI name (`midiToNoteName`) |
| Cents off (if melody) | nearest melody note vs current pitch (or `melodyPitch` fold) |
| Thin level bar | `rms` (green/amber/red; secondary to ribbon) |

Hide cents when no melody. Translucent card styles in `index.css`.

**B. First-run tip** (`localStorage` `vocalous.tipSeen`): dismissible Alert on practice mount — 3 bullets:

1. Green dots = on target pitch  
2. Bottom strip = your input level  
3. Stop → session score (pitch + timing)

**C. Help/About** `FAQ.COACH` section: same bullets + exercises / history / optional sidecar.

**D.** i18n keys in **all three** locales: `HUD.NOTE`, `HUD.CENTS`, `HUD.LEVEL`, `TIP.*`, `FAQ.COACH.*`.

## Risks

| Risk | Mitigation |
|------|------------|
| 49 grid lines dense on short screens | Label naturals only; alpha-halve accidental lines |
| `melodyPitch` fold can still place a dot one octave from sung pitch when far off | Rare; acceptable (scores against target octave) |
| Ribbon at rAF heavy on weak machines | Throttle ribbon samples to ~15 Hz if jank |
| No automated tests in repo | Manual build + browser pass only |
