# Plans

## Purpose

Hold durable implementation plans and design documents for Vocalous work (phased feature plans, architecture notes).

## Ownership

- All files under `plans/`.

## Local Contracts

- One primary plan file per major initiative; active roadmap: `singing-coach-roadmap.md`.
- Plans are point-in-time contracts for implementation: update the plan when scope/phase decisions change, or supersede with a new file and delete/archive stale claims.
- Do not store secrets, tokens, or personal data in plans.
- Status: Phases 0–5 implemented in-tree (client scoring, exercises, history, lyrics, sidecar skeleton); mark completion notes at top of the roadmap when verifying.

## Work Guidance

- Prefer editing the active plan over creating near-duplicates.
- When a plan is fully implemented, mark status at the top or remove the file if the repo no longer needs it.

## Verification

- None (docs only).
