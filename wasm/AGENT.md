# WASM pitch detectors

## Purpose

Own the Rust → WASM package wrapping the `pitch-detection` crate for browser use.

## Ownership

- All files under `wasm/` (`src/`, `Cargo.toml`, tests); build output `wasm/pkg/` (generated by `wasm-pack`, consumed by client Rollup).

## Local Contracts

- Package name: `pitch-detection-wasm` (must match client dependency `file:../wasm/pkg`).
- Crate type: `cdylib` + `rlib`; edition 2018.
- Dependencies: `wasm-bindgen`, `pitch-detection = "0.2"`; optional `console_error_panic_hook` (default), optional `wee_alloc`.
- Public exports (`src/lib.rs`): `AutocorrelationDetector`, `McLeodDetector` with `new(size, padding)` and `get_pitch(signal, sample_rate, power_threshold, clarity_threshold, pitch: &mut [f32])`.
- Output layout: `pitch[0] = frequency`, `pitch[1] = clarity`; no-pitch → `-1.0`, `0.0`.
- Build command: `wasm-pack build --target web` (from `wasm/`); repo root `./run` does this first.
- Release profile: `opt-level = "s"` (size).

## Work Guidance

- Keep JS-facing API stable: worker in `client/worker/` is the only in-repo consumer.
- Bump `pitch-detection` carefully; re-test McLeod vs autocorrelation on sung input after upgrades.
- Do not hand-edit `pkg/`; always rebuild with wasm-pack.

## Verification

- `cd wasm && wasm-pack build --target web`
- Optional: `cargo test` in `wasm/` when Rust toolchain available; browser path is exercised via client worker.
