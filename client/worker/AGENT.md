# Pitch detection worker

## Purpose

Own the dedicated Web Worker that loads pitch-detection WASM and serves `createDetector` / `getPitch` over post-me to the main thread.

## Ownership

- `client/worker/index.ts`, `client/worker/types.ts`
- Build output: `client/public/pitch-detection/worker.js` (generated by Rollup; do not hand-edit)

## Local Contracts

- Bundle format: IIFE via `client/rollup.config.js` (`input: worker/index.ts`).
- WASM init path: `./pitch_detection_wasm_bg.wasm` relative to worker script URL (`init('./pitch_detection_wasm_bg.wasm')`); Rollup copies `../wasm/pkg/**.wasm` beside the worker.
- Exposed methods (`WorkerMethods`): `createDetector(name, size, padding)` and `getPitch(signal, sampleRate, powerThreshold, clarityThreshold)` → `Float32Array` `[frequency, clarity]` or `[-1, 0]`.
- Detector names: `'mcleod' | 'autocorrelation'` (must match store `Detector` type in `src/model.ts`).
- One live detector at a time: `createDetector` frees any previous instance.
- Handshake: `ChildHandshake` / parent `ParentHandshake` (post-me) with retries as configured in `model.ts` `initializeWorker`.
- `padding` is currently `windowSize / 2` from `pitch-monitor.tsx`.

## Work Guidance

- Keep worker free of DOM/React imports.
- Protocol changes: update `types.ts`, worker `methods`, and `pitch-monitor.tsx` call sites in one change.
- Rebuild: `cd client && npm run build:worker`.

## Verification

- `cd client && npm run build:worker`
- Runtime: start app, press Start, confirm pitch dots update (worker handshake errors surface via error modal).
